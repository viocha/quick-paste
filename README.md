# quick-phrase

Windows 快捷短语应用，使用 Go、Wails 3、React 和 Bun。

- 开发：`wails3 dev`
- 构建：`wails3 build`
- 运行：`wails3 task run`
- 测试：`go test ./...`

构建产物位于 `bin/quick-phrase.exe`。启动时显示主界面，关闭窗口后驻留托盘。
短语数据保存在 `%APPDATA%/quick-phrase/phrases.json`。应用不包含旧版兼容或运行时迁移逻辑。

设置中可打开数据目录、配置全局快捷键、开机自启和 WebDAV。手动启动显示主界面，开机自启只驻留托盘。

WebDAV 填写已有目录的地址、账号和密码，保存后可测试连接。备份固定写入该目录下的 `quick-phrase/backup.json`，每次覆盖同一个文件。自动备份间隔默认 6 小时，可设为 1–168 小时；应用运行期间执行，重启后补做已到期的备份，失败后 15 分钟重试。

WebDAV 设置页可手动备份、查看云端与本地新增/删除/修改的条目及内容，再确认恢复。恢复覆盖本地短语和文件夹，操作前会在数据目录的 `recovery` 子目录保存原始数据副本；预览后本地数据变化时需重新预览。

连接配置保存在数据目录的 `backup-settings.json`，密码以明文保存在本地。远端备份只包含短语和文件夹，不包含连接配置和密码。

默认按 `Ctrl+Alt+Space` 打开或关闭短语浏览悬浮框。在“设置 → 常规 → 短语浏览快捷键”中按下新的组合键并保存，清空后保存可禁用；被其他程序占用时保留原设置并提示。快捷键保存在 `HKCU\Software\quick-phrase` 的 `BrowserHotkey` 值中。

先将光标放在目标输入位置，再按快捷键。悬浮框出现在输入光标附近，无法读取输入光标时回退到鼠标位置，并避让屏幕边缘。面板固定为 320 × 360，内容超出时内部滚动，展开或折叠文件夹不会改变面板高度。点击文件夹可展开或折叠，点击短语直接输入内容（内容为空时输入名称），输入成功后关闭；可拖动顶部 header 移动位置，按 Esc 或点击关闭按钮收起。点击面板外部或切换输入窗口时自动关闭。

主界面和短语浏览悬浮框都会在名称下显示单行内容摘要，超出宽度显示省略号；仅被截断的内容启用详情 tooltip，默认悬停 500ms 后显示，可在“设置 → 常规 → 详情提示延迟”修改（0–5000ms，自动保存并同步生效），每次进入都重新计时（`timeout=0`）。

悬浮框的详情 tooltip 使用独立无焦点窗口，优先显示在右侧，空间不足时显示在左侧；长详情可滚动，浏览面板的固定尺寸不变。
