# Quick Paste

Quick Paste 是一个使用 Go、Wails 3、React 和 Bun 构建的 Windows 快速粘贴工具。

- 开发：`wails3 dev`
- 构建：`wails3 build`
- 运行：`wails3 task run`
- 测试：`go test ./...`

构建产物位于 `bin/quick-paste.exe`。启动时显示主界面，关闭窗口后驻留托盘。
短语数据保存在 `%APPDATA%/quick-paste/phrases.json`。应用不包含旧版兼容或运行时迁移逻辑。

设置中可打开数据目录、配置全局快捷键、开机自启和 WebDAV。手动启动显示主界面，开机自启只驻留托盘。

WebDAV 填写已有目录的地址、账号和密码，保存后可测试连接。备份固定写入该目录下的 `quick-paste/backup.json`，每次覆盖同一个文件。自动备份间隔默认 6 小时，可设为 1–168 小时；应用运行期间执行，重启后补做已到期的备份，失败后 15 分钟重试。

WebDAV 设置页可手动备份、查看云端与本地新增/删除/修改的条目及内容，再确认恢复。恢复覆盖本地短语和文件夹，操作前会在数据目录的 `recovery` 子目录保存原始数据副本；预览后本地数据变化时需重新预览。

连接配置保存在数据目录的 `backup-settings.json`，密码以明文保存在本地。远端备份只包含短语和文件夹，不包含连接配置和密码。

默认按 `Ctrl+Alt+Space` 打开短语页，按 `Alt+V` 打开剪贴板页。两个快捷键都可在设置中修改或禁用；剪贴板也可接管 `Win+V`。

先将光标放在目标输入位置，再按快捷键。悬浮框优先出现在鼠标附近并避让屏幕边缘，固定为 380 × 480，内容在内部滚动。顶部可切换剪贴板和短语，两页均支持搜索。短语页可在文件夹中直接新建，并可编辑、移动或删除短语；点击短语向原输入窗口输入内容。悬浮框可拖动，按 Esc 或点击关闭按钮收起。

短语插入和短语补全默认使用 Ctrl+V，也可在设置中选择 Shift+Insert 或 SendInput。Ctrl+V 和 Shift+Insert 使用临时剪贴板，备份可安全复制的全部格式。支持读取编辑内容的控件会在预期文本实际插入后恢复；无法可靠读取编辑内容的控件（包括网页密码框、关闭无障碍支持的 Monaco、VS Code）在修改剪贴板和删除补全词前自动降级为 SendInput，沿用对应输入间隔设置。文本变化事件触发完成检查，缺少事件时只在当前事务内有限查询实际文本；2 秒内未确认完成时停止并恢复；已发送粘贴后不会重发 SendInput，以免重复输入。同步控件按目标进程读取并关闭剪贴板完成恢复。期间其他程序的新复制内容优先保留，临时短语排除 Windows 剪贴板历史、云同步和应用历史。无法安全备份的句柄格式或超过 256 MB 的备份也自动降级为 SendInput；恢复时若剪贴板持续被占用，会在有限重试后报告恢复失败。SendInput 直接模拟文字输入，不使用剪贴板。

输入时自动补全按文件夹显式开启，所有文件夹默认关闭。右键文件夹可开启或关闭；开启后，该文件夹及所有子文件夹中的短语都会参与自动补全，子文件夹无需重复开启。根目录短语不参与自动补全，手动浏览和搜索不受此开关影响。

剪贴板默认开启，可在“设置 → 剪贴板”中关闭。历史保存在 `%APPDATA%/quick-paste/clipboard`，不会上传到 WebDAV，也不按时间自动删除。默认最多 10000 条普通记录、总占用上限 64 MB；文本、富文本和文件列表的单项上限为 2 MB，图片单项上限为 16 MB，这四项都可在设置中调整。置顶项目不会自动删除，但计入总占用；全部空间被置顶项目占满时暂停接收新项目并提示清理。

支持 Unicode 文本、HTML/RTF 富文本、位图和本地文件列表。图片没有可靠的外部路径，因此复制像素数据到应用历史。文件历史只保存系统剪贴板中的路径列表，不复制文件内容，实际文件大小也不计入历史占用；粘贴前会检查原文件是否仍存在，原文件被移动或删除后该记录将无法粘贴。

剪贴板项目点击后以原格式粘贴；富文本可按中键或右键菜单“以纯文本粘贴”进行纯文本粘贴。悬停显示预览和复制、置顶、更多、删除操作；使用成功的项目会移到所属分组顶部。图片可显示缩略图和详情预览，来源应用显示程序图标和名称，无法识别时使用通用图标。

主界面和短语浏览悬浮框都会在名称下显示单行内容摘要，超出宽度显示省略号；仅被截断的内容启用详情 tooltip，默认悬停 500ms 后显示，可在“设置 → 常规 → 详情提示延迟”修改（0–5000ms，自动保存并同步生效），每次进入都重新计时（`timeout=0`）。

悬浮框的详情 tooltip 使用独立无焦点窗口，优先显示在右侧，空间不足时显示在左侧；长文本和图片详情可滚动，浏览面板的固定尺寸不变。
